# solo-v2 — 1인 웹 체험판 버전 2

[solo/](../solo/README.md)(v1)의 13장면 흐름은 그대로 두고, **탑승자 캐릭터 · 생존 · 손 인식 · 시각효과**를 더한 버전.
v1은 건드리지 않았다.

```powershell
npm run dev   # → http://localhost:8080/sprint/solo-v2/
```

카메라(얼굴 스캔 · 손 인식)는 `http://localhost` 또는 https 에서만 브라우저가 허용한다. 카메라가 없거나 거부해도 마우스만으로 끝까지 진행된다.

## v2에서 추가된 것

| 기능 | 내용 | 파일 |
| --- | --- | --- |

| 하단 상태창 | 초상 + 이름 + VITAL(0~100) + 상태(정상/불안정/위독) + 최근 사건. 피해를 입을수록 초상이 깨지고 노랑→빨강으로 변한다 | `js/vital.js` |
| 실패와 사망 | 장면마다 실패 조건이 VITAL을 깎는다. 0이 되면 초상이 분해되며 `SIGNAL LOST` → **이 장면에서 재조립(VITAL 50)** 또는 **처음부터** | `js/vital.js` |

| 시각효과 | 블룸, 스캔라인·비네트, 글리치, 화면 흔들림, 파티클, 충격파, 워프 스트릭, 홀로그램 고스트 | `js/fx.js` |

## 손 인식 조작

- 우상단 `HAND` 버튼 또는 첫 화면의 "손 인식 조작" 버튼으로 켠다. 인터넷 필요(공연판과 같은 jsDelivr CDN의 `@mediapipe/hands@0.4`).
- 카메라 프레임 가운데 76%가 화면 전체로 매핑된다 (`hands.js` 의 `mapX/mapY`).
- 핀치 판정: 0.7 이상에서 눌림, 0.42 아래에서 놓임 (히스테리시스).
- 물레: 두 손이 보이면 양손 높이의 평균 = 빚는 높이, 양손 간격의 절반 = 반지름, 핀치할수록 좁게.
- 손이 화면에서 사라지면 마우스가 다시 포인터가 된다.

## 사워도우 레시피 (js/recipes.js)

마지막 카드는 고정 문구가 아니라 **플레이 결과로 만들어지는 실제 배합표**다.

| 플레이 결과 | 레시피에 반영 |
| --- | --- |
| 발효 장면의 물·밀가루 균형 | 수화율 (65~84%) |
| 발효 온도 | 1차 발효 시간, 르뱅 비율 |
| 빚은 그릇의 실루엣 | 성형 (불 / 바타르 / 틴) |
| 신호 동기화율 | 부재료 등급 — 50% 미만 흔함, 50%+ 드묾, 90%+ 희귀 |
| 그릇 일치도 85%+ | 부재료 하나 더 |
| 재조립(사망) 횟수 | 접기 횟수 +1~2 |

밀가루 배합(5종)은 무작위.

**현재 `DATA` 는 임시 데이터다.** 일반적인 사워도우 배합 범위로 채운 값이고 직접 구워 검증하지 않았다. 카드 하단에 "시험판 배합" 문구가 찍힌다.
본인 레시피로 바꾸는 방법 — `js/recipes.js` 의 `DATA` 만 고치면 된다:

- `bases` : `{ id, name, flours: [[이름, %], ...], hyd: 수화율 보정 }`
- `addins` : `{ id, tier: 1|2|3, name, items: [[재료, %], ...], when: 넣는 시점, hyd?, note?, pair? }`
- `shapes`, `salt`, `bake`, `flourTotal`(한 덩이 밀가루 g)
- 검증이 끝나면 `placeholder: false` → 카드의 시험판 문구가 사라진다.
- 배열 **순서를 바꾸거나 중간을 지우면 이전에 공유된 링크가 다른 레시피를 가리킨다** (링크는 배열 번호를 담는다). 추가는 맨 뒤에.

### 공유 링크

영수증 화면의 "공유 링크 복사" → 레시피가 URL 뒤 `#r=…` 에 담긴다. 서버 없음. 얼굴 사진은 담기지 않는다(기본 헬멧으로 표시).
그 링크로 들어오면 플레이 없이 카드가 바로 열리고 "나도 탑승하기"로 체험을 시작할 수 있다.

## 나만의 빵 (js/bake.js)

recipe 다음, credits 앞에 들어가는 14번째 장면.

1. **넣기** — 레시피 카드를 끌거나 클릭해 오븐 투입구로.
2. **굽기** — 껍질 색 게이지가 약 11초 동안 오른다. `[지금 꺼내기]`를 누른 순간이 껍질 색(덜 익음 / 황금 / 진함 / 탐). 끝까지 두면 탄다.
3. **빵** — 레시피가 모양을 정한다: 성형(불·바타르·틴) = 실루엣, 밀가루·말차·쑥·카카오 = 색, 부재료 = 알갱이, 수화율 = 자른 단면의 기공 크기. 김과 향 글자가 피어오른다.
4. **가져가기**
   - `JPG 저장` — 빵 + 영수증을 한 장으로.
   - `공유 · 카톡 · 메시지` — 폰에서는 기기의 공유 창(카카오톡·메시지·메일 등)으로 JPG와 레시피 링크를 보낸다. 공유 창을 지원하지 않는 PC 브라우저에서는 JPG를 저장한다.
   - `메일로` — JPG를 저장하고 레시피 본문이 채워진 메일 작성 창을 연다. (웹 페이지는 메일에 파일을 직접 첨부할 수 없어 첨부는 손으로.)

부재료별 알갱이 색·향 문구는 `bake.js` 상단의 `SPECK` / `TINT` / `SCENT` — `recipes.js` 에 부재료를 추가하면 같은 `id` 로 여기에도 추가.
